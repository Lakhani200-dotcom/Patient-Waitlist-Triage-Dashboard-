## Project Overview 
- This project was created using Excel to support patient triaging and scheduling based on medical discipline, treating therapist, preferred appointment day and time, and scheduling status. 
## Features
- Interactive dashboard with slicer filters for efficent data exploration. 

Pivot tables connected to slicers, allowing users to filter by:
- Treating therapist
- Medical discipline
- Patient name
- Next scheduled appointment
- Diagnosis

Stacked bar chart:
- Displaying patient counts by scheduling status (Initial Evaluation & Follow-Up Visit).
## Tools Used
  - Microsoft Excel
  - Claude AI (Assisted with user interface design ideas)
  ## Key Insights
  - Provides a dynamic visualization of patients on the waitlist for a multidisciplinary medical facility to seamlessly schedule and patients identify patients who can be scheduled when therapist cancellations occur.
  - The various filter options curates data based patient information and specific scheduling criteria.
